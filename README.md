# IBM Applied Data Science Capstone: SpaceX Falcon 9 Landing Prediction

## Project Overview
The objective of this capstone project is to predict whether the first stage of a SpaceX Falcon 9 rocket will successfully land (`Class 1`) or fail/crash (`Class 0`). Using data science techniques—ranging from API data collection and web scraping to SQL querying, interactive geospatial mapping, dashboards, and machine learning classification—this project evaluates the economic and operational feasibility of rocket reusability.
